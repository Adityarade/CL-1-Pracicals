# CL-1 Machine Learning Practicals

This repository contains the practical notebooks, datasets, reports, and supporting files for CL-1.

The weather API practical reads its OpenWeatherMap credential from the `OPENWEATHER_API_KEY` environment variable. In PowerShell, set it before starting Jupyter:

```powershell
$env:OPENWEATHER_API_KEY = "your_api_key"
jupyter notebook
```

Do not commit API keys or other credentials.
